# Picture Furnace test checklist

- Upload PNG/JPEG/WebP
- Enhance Natural returns edited image
- Enhance Blurry Image returns reconstructed image
- Enhance Beauty preserves identity while polishing
- Remove Background returns transparent PNG
- Custom Replace/Add/Remove/Change Color commands work
- Before/After view shows original and forged result
- Undo and Redo navigate edit history
- Reset returns to original
- Save downloads current result
